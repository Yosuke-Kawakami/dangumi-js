見出し１ H1

本文はこんな感じで好きに書いてしまって問題ありません。行頭のインデントや一行あたりの文字数は CSS 部分で調整可能です。

ご覧のように大文字英数字は縦向きで記載しますが、半角英数字は横向きに記載します。このあたりは一般的な段組みスタイルを踏襲しています。

見出し２ H2

HTML タグは自由に利用可能ですが描画部分の処理の都合上（行の幅を）適宜 CSS で調整する必要があります。調整し損なった場合はテキストの折り返し位置で文字列が見切れしてしまいます。

今後の展望

このコードは習作がてらに試作してみたものです。全体的なクオリティはまだまだ低いです。文字列の高さを調整する部分は特に使いづらい箇所かなという自覚があります。

更新時期は約束できませんが、パラメーターを用いて簡単にデザインを調整できる方向で改修を予定しています。

ぶっちゃけてしまいますがレンダリングエリアと入力エリアを分けて処理しているのは如何なものかと思っています。どエレガントな素晴しい実装方法をご存知の方がいらっしゃいましたらコッソリと教えていただけますと変態が大変喜びます。
